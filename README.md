# Modern HTML Tech Portfolio Website

A modern, responsive, and feature-rich portfolio website built with HTML5, CSS3, and JavaScript. Perfect for showcasing your projects, skills, and experience as a developer.

## Features

✨ **Modern Design**
- Clean and professional layout
- Smooth animations and transitions
- Gradient backgrounds and glassmorphism effects
- Responsive design for all devices

🏗️ **Key Sections**
- **Hero Section** - Eye-catching introduction with call-to-action buttons
- **About Section** - Professional biography with statistics
- **Projects Showcase** - Grid layout for displaying your work
- **Skills Section** - Organized skill categories
- **Contact Section** - Contact information and message form
- **Navigation** - Sticky header with smooth scrolling

📱 **Responsive**
- Mobile-first design
- Hamburger menu for mobile devices
- Optimized layouts for tablets and desktops

🎨 **Interactive Elements**
- Smooth scroll navigation
- Hover effects on cards and buttons
- Active navigation link highlighting
- Form validation
- Scroll animations

## How to Use

1. **Clone or download** this repository
2. **Open `index.html`** in your web browser
3. **Customize** the content:
   - Update your name and bio
   - Add your projects and descriptions
   - Update contact information
   - Replace placeholder images
   - Modify colors in CSS variables (`:root` section in `styles.css`)

## Customization

### Colors
Edit the CSS variables at the top of `css/styles.css`:

```css
:root {
    --primary-color: #6366f1;      /* Main accent color */
    --secondary-color: #ec4899;    /* Secondary color */
    --dark-bg: #0f172a;            /* Dark background */
    --light-bg: #f8fafc;           /* Light background */
    /* ... more colors ... */
}
```
