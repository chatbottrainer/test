# Data Analyst Portfolio Website

A modern, responsive, and professional portfolio website for data analysts, built with HTML5, CSS3, and JavaScript. Perfect for showcasing your analytics projects, skills, and experience.

## Features

✨ **Modern Design**
- Clean and professional layout optimized for data professionals
- Smooth animations and transitions
- Gradient backgrounds and modern effects
- Fully responsive design for all devices

📊 **Key Sections**
- **Hero Section** - Eye-catching introduction highlighting your data expertise
- **About Section** - Professional biography with career statistics
- **Projects Showcase** - Grid layout for displaying your analytics projects
- **Skills Section** - Organized skill categories (Visualization, Programming, Databases, Specialized Skills)
- **Contact Section** - Contact information and project inquiry form
- **Navigation** - Sticky header with smooth scrolling

📱 **Responsive**
- Mobile-first design
- Hamburger menu for mobile devices
- Optimized layouts for tablets and desktops

🎨 **Interactive Elements**
- Smooth scroll navigation
- Hover effects on cards and buttons
- Active navigation link highlighting
- Form validation
- Scroll animations

## How to Use

1. **Clone or download** this repository
2. **Open `index.html`** in your web browser
3. **Customize** the content:
   - Update your name and professional title
   - Add your analytics projects with descriptions
   - Update contact information
   - Replace placeholder images with project screenshots
   - Modify colors in CSS variables (`:root` section in `styles.css`)

## Customization

### Colors
Edit the CSS variables at the top of `css/styles.css`:

```css
:root {
    --primary-color: #6366f1;      /* Main accent color */
    --secondary-color: #ec4899;    /* Secondary color */
    --dark-bg: #0f172a;            /* Dark background */
    --light-bg: #f8fafc;           /* Light background */
    /* ... more colors ... */
}
```
